# Excel Projects

Data analysis projects built in Microsoft Excel, from cleaning raw data to summarizing it with pivot tables and presenting it in an interactive dashboard.

## Project 01: "Bike Sales Dashboard"

**File:** `Project_01.xlsx`

**Goal:**  "Find which customer groups are most likely to buy a bike."

1,000 customer records with demographics and purchase status."

**Process**
1. **Cleaning:** removed duplicates, standardized text values and fixed data types
2. **Transformation:** added helper columns, e.g. grouping ages into brackets with `IF` formulas
3. **Analysis:** built pivot tables to compare groups
4. **Dashboard:** combined pivot charts and slicers into one interactive view

**Excel skills used:** pivot tables, pivot charts, slicers, `XLOOKUP`/`VLOOKUP`, `IF`, conditional formatting and data validation. *(Keep only the ones you used.)*
